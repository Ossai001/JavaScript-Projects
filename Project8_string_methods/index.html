JavaScript String and Number Methods

concat() Method

slice() Method

toUpperCase() Method

The toUpperCase() method converts all the letters in a string to uppercase.

search() Method

The search() method returns the position of the first occurrence of specified text within a string.

toPrecision() Method

The toPrecision() method formats a number to a specified number of significant digits and returns it as a string.

toFixed() Method

The toFixed() method formats a number using a specified number of digits after the decimal point and returns a string.

valueOf() Method

The valueOf() method returns the primitive value stored inside a JavaScript object.
