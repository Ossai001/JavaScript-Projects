## Pizza Menu

The Pizza Menu is an interactive ordering application. Customers can choose the size of the pizza as well as the meat and vegetable toppings. JavaScript gathers the choices, figures out the overall cost, and shows the order receipt.

Technologies used:

- HTML
- CSS
- JavaScript
- Arrays
- Loops
- Functions
- DOM manipulation

## Tic-Tac-Toe Game

The traditional Tic-Tac-Toe game has been made interactive. JavaScript controls the game rules, looks for winning combinations, and resets the board following a victory or draw as players alternately choose squares.

Customized pictures, sounds, and an animated line that indicates the winning combination are all included in the game.

Technologies used:

- HTML
- CSS
- JavaScript
- Canvas
- Event handlers
- Images and audio
